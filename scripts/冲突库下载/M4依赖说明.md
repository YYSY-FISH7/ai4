# M4 隔离依赖

入口：`bash scripts/冲突库下载/install_m4_deps.sh --check`，首次安装显式使用 `--install`。

目标 `lib/m4/`，Python 3.8 / Ubuntu 20.04 / ROS Noetic，CPU torch 2.4.1+cpu、torchvision 0.19.1+cpu、ultralytics 8.4.173、NumPy 1.21.6，辅助包固定见 m4-requirements.lock。不安装 opencv-python，不修改系统 NumPy/cv2。

这是现有旧 ROS 环境的隔离兼容方案；部分第三方元数据要求比固定 NumPy 更高，故使用显式 --no-deps，不能宣称满足全部上游依赖声明。必须以导入、NMS、真实模型推理和 ROS E2E 验证可用性。尚未在全新空目录重装验证；安装器先暂存并自检，再移动为 lib/m4，失败不覆盖已有环境。

最新版 develop 实际登记文件为 scripts/冲突库下载/冲突库汇总.md；合并 PR 时更新其中 M4 段，保留其他模块记录。根目录旧登记文件本轮不覆盖。
