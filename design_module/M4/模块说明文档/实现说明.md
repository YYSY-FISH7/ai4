# M4 实现说明

范围：code/detector.py、visual_tracker.py、对应四个 notebook，相机/检测/跟踪节点及其配置、launch、M4 测试、独立演示和依赖工具。未修改 design/、skill/、共享数据类型和其他模块源码。实际 ROS 类型继续使用组长已有定义。

## 本轮修正

- 检测门槛 0.1 与跟踪低分门槛一致；防止检测器提前丢弃第二阶段关联所需目标。
- 关联同时检查类别，防止同位置不同类别继承原 ID；禁止 NaN/无穷、非法宽高和非法门槛污染状态。
- 检测订阅仅缓存最新帧，独立线程推理，避免慢推理导致持续处理积压旧图；开发阶段错误明确退出，不能伪装空场景。
- 相机循环使用视频帧位置属性；中转输入输出解析后相同则拒绝启动，避免自订阅循环。话题通过 launch 参数指定。
- 独立控制台追踪自己创建的进程组，停止不使用全局 pkill；模拟演示和实际仿真输入明确分开，图像过期和进程退出在页面体现。
- 测试隔离 master；正式联调只观察真实双方节点，缺目标、缺状态转换不得通过。
- 四个 notebook 从头真实运行，移除假框兜底；合成数据与实际推理分别标注，不再以面积占比宣称物理距离。
- 唯一公开操作文档及 scripts/run_m4.sh 一键入口；旧脚本路径保留必要兼容转发，旧重复文档移入仓库外备份。

## 当前边界

跟踪是卡尔曼匀速模型 + 两阶段 IoU + 贪心匹配的简化版本，GMC/ReID 尚未启用，非完整 BoT-SORT。track_buffer 按处理帧计数；面积比为框面积除以实际图像面积。图像与检测消息因既有接口缺少共同时间戳，不宣称严格时间同步。未训练无人机权重，未完成整套飞行闭环与队友仿真验收。源码工作空间可运行，catkin install 分发需另行完善共享构建配置。

## 历史决定

此前组长已同意跟踪函数保留可选 image 参数、M4 冲突依赖隔离及现阶段暂缓 GMC/ReID/训练。原讨论和旧文档保存在 VM 本轮修改前的仓库外备份；本说明不把历史建议视为新的用户授权。公共依赖登记和构建配置变更需在 PR 中单独标出。
