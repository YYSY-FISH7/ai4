# M4 视觉检测

职责：code/detector.py、detector_node.py、YOLO推理；/camera/image_raw→/detections，另有/detector/debug_image。M5订阅检测执行跟踪，M8订阅检测作为节拍。M4不发布航迹，不直接连接M6。

在已有M0会话中source /opt/ros/noetic/setup.bash、catkin_ws/devel/setup.bash及本次connection.bash。使用既有test/flow/M0-M4/run.sh --connection <本次连接文件> --model <已核验YOLO11s ONNX>可启动兼容的M4+M5组合入口；组合便利入口不代表M5属于M4。单独检测入口为同一Python环境运行test/flow/M0-M4/python/run-detector-ort1.py catkin_ws/src/uav_tracking/scripts/detector_node.py _model_path:=<ONNX> _imgsz:=640 _conf_thres:=0.50，须按模型与依赖说明设置PYTHONPATH至lib/m4与lib/m4_onnx。

依赖和可信模型获取见模块说明文档/模型与依赖.md。测试：python3 -m pytest -q test/detector。已有103项联合历史结果非本轮新测试，本轮回归另见M5说明的regression日志。

本模块证据在test/flow/M0-M4/。低置信、漏检和主动跳帧保留；自然锁定未通过，不降0.8门槛。跟踪、航迹和ID说明见../M5/模块使用文档.md。
