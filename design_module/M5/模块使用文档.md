# M5视觉跟踪独立使用

正式验收只覆盖本组M4视觉检测、M5视觉跟踪：实时Gazebo输入→真实算法→实时检测/航迹输出与展示。M3/M6/M8的算法处理由对应负责人验收，不作为本方完成前提。

code/visual_tracker.py及visual_tracker_node.py接收/detections（uav_tracking/Detections），辅助/camera/image_raw取实际图像尺寸，输出/visual/tracks（uav_tracking/VisualTrackArray）。字段id、原像素xywh bbox、area_ratio=w*h/(实际宽*高)。无Header数组不声称精确同帧。算法/配置不改，high=.5 low=.1 new=.6 match=.8 buffer=30保留。

## 真实会话启动

```bash
cd /home/demo/ai4-m4-m5-formal-20261116
source /opt/ros/noetic/setup.bash
source catkin_ws/devel/setup.bash
source <本次M0运行目录>/connection.bash
export ROS_PACKAGE_PATH="$PWD/catkin_ws/src:$ROS_PACKAGE_PATH"
roslaunch uav_tracking visual_tracker.launch
```

已有M0/M4真实相机与检测时启动；如果M0-M4组合run.sh已启动跟踪器，不重复启动。M5本身不加载YOLO、不另起roscore。只读观察rostopic echo /visual/tracks；Ctrl+C停本节点。实际模型与隔离依赖启动见M4说明。
