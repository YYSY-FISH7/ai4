# M5 视觉跟踪独立使用

实现：code/visual_tracker.py、catkin_ws/src/uav_tracking/scripts/visual_tracker_node.py，配置config/visual_tracker.yaml。输入/detections（uav_tracking/Detections），辅助订阅/camera/image_raw取实际尺寸；输出/visual/tracks（uav_tracking/VisualTrackArray）。bbox是原像素左上角xywh，area_ratio=w*h/(实际宽*高)。检测输入没有Header，不宣称精确同帧配对。

## 快速启动

```bash
cd /home/demo/ai4-m4-m5-delivery-20261116
source /opt/ros/noetic/setup.bash
source catkin_ws/devel/setup.bash
source <当前M0本次运行目录>/connection.bash
export ROS_PACKAGE_PATH="$PWD/catkin_ws/src:$ROS_PACKAGE_PATH"
roslaunch uav_tracking visual_tracker.launch
```

必须已有M4发布/detections，不额外启动roscore。相机输入默认同一/camera/image_raw；原参数high=.5 low=.1 new=.6 match=.8 buffer=30不变。仅运行M5时不加载YOLO。Ctrl+C停止本节点。组合检测跟踪入口兼容保留在M0-M4/run.sh。
